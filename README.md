# CRUD de Tareas con Login (Node.js + Express + SQLite)

Proyecto de gestión de tareas con sistema de Login y CRUD integrados en un solo archivo `index.html`.

## Requisitos
- Tener instalado Node.js

## Instalación

1. Clonar el repositorio:
git clone https://github.com/rosarioduranrosmery0909-beep/crud-de-tareas.git

2. Entrar a la carpeta del proyecto:
cd crud-de-tareas

3. Instalar dependencias:
npm install

## Ejecución

1. Ejecutar el servidor:
node server.js

2. Abrir en el navegador:
http://localhost:3000

## Funcionamiento

1. Registrarse con un correo y contraseña
2. Iniciar sesión
3. Gestionar las tareas (crear, ver, eliminar)

## Tecnologías usadas
- Node.js
- Express
- SQLite
- HTML, CSS y JavaScript
